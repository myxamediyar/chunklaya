# results

One directory per run. Each has `run.log` (what the script printed) and `results.json` (every row).
Scores are from `laya-multilingual` in fp32 on an M4 Pro via MPS; timings are for that hardware only.

| directory | what | script |
|---|---|---|
| `2026-09-19-maxlen/` | raw Laya at 1024 / 2048 / 4096; first needle test | `eval/exp_maxlen.py` |
| `2026-09-19-chunked/` | fixed token windows, noul detector — the negative result; Exp 3 offset sweep | `eval/exp_chunked.py --n 30` |
| `2026-09-20-para/` | paragraph chunks, noul detector (0.596); `detectors.json` from `exp_detector.py` | `--configs para,750/750` |
| `2026-09-20-para-choice/` | paragraph chunks, choice detector, raw pool, n=30 (0.874) | `--detector choice` |
| `2026-09-20-para-choice-clean/` | same, pool cleaned, n=30 (1.000) | `--clean-haystack 0.2` |
| `2026-09-20-n100-raw/` | **headline**: n=100, raw pool, bootstrap CIs | `--n 100 --configs para,750/750 --detector choice` |
| `2026-09-20-n100-clean/` | n=100, cleaned pool | `--n 100 --configs para --detector choice --clean-haystack 0.2` |
| `2026-09-20-needle-vs-jev-prefilter/` | **Jev comparison**: jev-decision-bench's needle tasks (1k/12k/24k, n=60, same items as the published Jev output) with `prefilter="bm25", top_k=1`. AUC 0.993 vs Jev 1.000, flat across sizes; BM25 puts the needle passage first in 180/180 documents; Laya scores 1 chunk instead of up to 126 | `eval/exp_needle_vs_jev.py --arms noul,choice --prefilter bm25 --top-k 1` |
| `2026-09-20-needle-vs-jev/` | the same tasks with every chunk scored (no prefilter): raw / noul / choice arms. AUC 0.97 at 1k falling to 0.66 at 24k — the per-chunk false-positive rate times ~125 chunks, the cost the prefilter removes. Laya on the needle sentence alone is 0.994 | `eval/exp_needle_vs_jev.py` |
| `2026-09-22-needle-scale/` | **Update 2**: the benchmark's 60 needles in unique SQuAD-train filler at 24k / 100k / 300k / 1M tokens. `bm25@1` AUC 0.993 at every size, 0.92 s/doc at 1M; `bm25@5` and every-chunk at chance | `eval/exp_needle_scale.py` |
| `2026-09-22-index-timing/` | `ChunkLaya.index` on a 1M-token document: 0.98 s/question re-chunking vs 0.93 s once + 0.015 s/question | (smoke test tail) |
| `2026-09-22-scale-semantic/` | **Update 2**: sports needle vs haystack size m = 70…5600 over the full AG News test split, full scan and bge-small top-k, raw / Laya-cleaned / hand-relabelled pools. `flagged.json` is the 77 passages behind `eval/data/ag_news_full_relabels.json` | `eval/exp_scale_semantic.py` |
| `2026-09-22-tail/`, `2026-09-22-tail-dense/` | detector rephrasings (2-way, 5-way with a distractor class, strict 4-way, means, mins, two-stage) and a bge cosine gate against the false-positive tail; none flattens the curve | `eval/exp_tail.py`, `eval/exp_tail_dense.py` |
| `2026-09-22-ranker/` | recall@k of BM25 / bge-small / RRF hybrid on the sports needle at m≈70 and m=877 | `eval/exp_ranker.py` |
| `2026-09-22-window-sweep/` | small token windows (256/128, 200/100, 128/64) on the headline task, n=100: 0.62–0.73 vs paragraph mode's 0.88 | `eval/exp_chunked.py --configs para,256/128,200/100,128/64` |
| `jev-decision-bench-needle/` | **not ours** — per-item Jev needle-test output copied from [OmarMujahid/jev-decision-bench](https://github.com/OmarMujahid/jev-decision-bench) (MIT, `jev-1.13.0`, run 2026-09-18), used by `eval/jev_needle_by_depth.py` | — |
| `cache/` | row-level prediction cache; gitignored, regenerated by any run | — |

`ms/doc` figures in the n=100 logs are cache-inflated (3–20 ms) — see the README's cost note. The
model's real cost is in `2026-09-19-chunked/` and the batch sweep quoted in the README.
