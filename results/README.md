# results

One directory per run. Each has `run.log` (what the script printed) and `results.json` (every row).
Scores are from `laya-multilingual` in fp32 on an M4 Pro via MPS; timings are for that hardware only.

| directory | what | script |
|---|---|---|
| `2026-09-19-maxlen/` | raw Laya at 1024 / 2048 / 4096; first needle test | `eval/exp_maxlen.py` |
| `2026-09-19-chunked/` | fixed token windows, noul detector — the negative result; Exp 3 offset sweep | `eval/exp_chunked.py --n 30` |
| `2026-09-20-para/` | paragraph chunks, noul detector (0.596); `detectors.json` from `exp_detector.py` | `--configs para,750/750` |
| `2026-09-20-para-choice/` | paragraph chunks, choice detector, raw pool, n=30 (0.874) | `--detector choice` |
| `2026-09-20-para-choice-clean/` | same, pool cleaned, n=30 (1.000) | `--clean-haystack 0.2` |
| `2026-09-20-n100-raw/` | **headline**: n=100, raw pool, bootstrap CIs | `--n 100 --configs para,750/750 --detector choice` |
| `2026-09-20-n100-clean/` | n=100, cleaned pool | `--n 100 --configs para --detector choice --clean-haystack 0.2` |
| `jev-decision-bench-needle/` | **not ours** — per-item Jev needle-test output copied from [OmarMujahid/jev-decision-bench](https://github.com/OmarMujahid/jev-decision-bench) (MIT, `jev-1.13.0`, run 2026-09-18), used by `eval/jev_needle_by_depth.py` | — |
| `cache/` | row-level prediction cache; gitignored, regenerated by any run | — |

`ms/doc` figures in the n=100 logs are cache-inflated (3–20 ms) — see the README's cost note. The
model's real cost is in `2026-09-19-chunked/` and the batch sweep quoted in the README.
